# Constraints — traps, barriers, and control

**Parent:** store-placeable. Catalog: [store_items.md § Traps](../../../Design/store_items.md#traps-barriers-and-control).

## Must honor

- **Grid:** one gameplay cell ≈ **300 UU** (10 ft) unless the concept is an explicit multi-cell set-piece ([General.md](../../../Design/General.md)).
- **Placement:** store drops on **empty room square** (≥2×2 room); some items may need edge/block rules later (Mirage Veil, Crystal Barricade) — call out if proposing similar.
- **Workers:** re-arm spent traps **between raids** by default; optional **small mana** cost; captive/set-piece exceptions per [time-passage-plan.md](../../../todo/time-passage-plan.md).
- **Raid lock:** no new placement during **active raid**; traps already placed still run; strategic time pauses.
- **Invaders:** party AI, trap literacy tags, composition counters — [Invaders.md](../../../Design/Invaders.md); propose `Knows_*` tags when relevant.
- **Balance:** avoid trivial full-party shutdown and avoid “always ignorable” — party comp / gear should matter.
- **Powered room:** some hazards only work when room is powered (pattern: Spore Generator) — state explicitly.

## Brainstorm checklist

- Trigger, footprint, one-shot vs reset, witness/learning, defender friendly-fire.
- Combos: mirror + beam, bait + trap, smoke + concealment, siphon / essence room hooks.
- Visual: basalt, quartz, ley glow — not mud-and-torches ([General.md](../../../Design/General.md)).
